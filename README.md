# RC Bíblia

App de Bíblia (leitura, estudo com IA, planos de leitura, devocional, escritor de
sermões/anotações) da Renovada Church.

Stack: React + Vite + TypeScript, Supabase (backend/auth/DB/edge functions),
Capacitor (app nativo Android/iOS), deploy na Vercel.

Veja `PROJECT_STATUS.md` para o contexto completo do projeto e `AGENTS.md` para
as regras de contribuição.

## Desenvolvimento

```bash
npm install
npm run dev
```
